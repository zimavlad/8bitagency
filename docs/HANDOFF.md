## Правила роботи (обовʼязково)
- Секрети тільки в змінних оточення або в scratchpad-файлі; ніколи в репозиторії, комітах, логах, чаті.
- Не чіпати інші проєкти на сервері, coolify*, проксі, ufw.
- У комітах і коді — без ідентифікаторів моделей у тексті комітів.

- Логи й прогони читати самому, а не просити Влада шукати.
- Не давати оцінок часу в людських годинах.
- Деплоїти тільки коли Влад сказав «деплой». Перед деплоєм перевір, чи ніхто не грає (за логами останніх хвилин).

## Інфраструктура
- Стек: SvelteKit 2 + Svelte 5 + TypeScript + vitest, adapter-node, Docker.
- Сервер: Coolify. API: `https://coolify.91.99.8.73.sslip.io/api/v1`. Застосунок uuid `6nhhj4epymmejq04xjg2kymr`.
- Домени гри: https://8bitagency.duckdns.org (основний), https://8bitagency.91.99.8.73.sslip.io.
- У змінних середовища Claude має бути `COOLIFY_TOKEN` (Влад додав). Решту ключів бери з Coolify сам:
  - `GET /applications/6nhhj4epymmejq04xjg2kymr/envs` з `Authorization: Bearer $COOLIFY_TOKEN` → там `ADMIN_TOKEN`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`.
  - Збережи їх у scratchpad-файл (наприклад `.coolify.env`), не друкуй значення у вивід.
- Деплой: `POST /deploy?uuid=6nhhj4epymmejq04xjg2kymr`, потім опитувати `GET /deployments/<deployment_uuid>` до `finished`/`failed`.
- Адмінка гри (Bearer ADMIN_TOKEN):
  - `GET /api/admin/logs?days=N&lines=M` — події (`run_start`, `run_phase`, `player_load`, `model_call`, …);
  - `GET /api/admin/runs` — список архівів прогонів; `GET /api/admin/runs/<id>` — повний прогін: `state` (елементи, вердикти, кроки) і `trace` (кожен запит і відповідь моделі);
  - `PUT /api/admin/knowledge/<role>/<file>` з `content-type: text/markdown` — база Джіпітенка.
- Лічильник грошей API у грі — спільний на сервер: `GET /api/game` → `game.ledger`. Щоб врахувати витрати поза грою (живі тести), постав новий залишок: `POST /api/game` `{"action":"balance","provider":"claude"|"gemini","usd":<залишок>}` (залишок = usd − spent − витрати тесту). Лічильник має бути завжди актуальним.
