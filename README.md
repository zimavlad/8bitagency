# 8BIT AGENCY

Віртуальний ізометричний офіс, у якому працює креативна агенція з трьох автономних агентів.
Ви даєте бриф — вони думають, сперечаються і видають готове рішення. Думки з'являються
в «баблах» над персонажами в реальному часі.

**Демо:** https://zimavlad.github.io/8bitagency/

## Команда

| | Хто | Роль | Що видає у фіналі |
|---|---|---|---|
| 🔴 | **Макс** | стратег | позиціонування одним реченням |
| 🟢 | **Віра** | копірайтерка | назву бренду та слоган |
| 🟣 | **Піксель** | дизайнер | концепцію логотипу + SVG |

## Як працює симуляція

Три раунди, у кожному агенти висловлюються по черзі:

1. **Аналіз** — кожен за своїм столом самостійно розбирає бриф.
2. **Обговорення** — усі сходяться за столом переговорів і реагують на думки колег
   (кожен бачить, що сказали двоє інших).
3. **Фінал** — повертаються за столи й видають свою частину рішення.

Кожен агент — окремий виклик Claude зі своїм системним промптом. Контекст колег
передається у промпт, тому в другому раунді вони справді сперечаються з конкретними
тезами один одного, а не говорять у порожнечу.

## Запуск

Статика без збірки — достатньо відкрити `index.html` або віддати теку будь-яким
статичним сервером:

```bash
npx serve .
```

**API ключ.** Вставте Anthropic API key у панелі — він зберігається лише в
`localStorage` вашого браузера і йде напряму з браузера в `api.anthropic.com`.
Без ключа працює демо-режим із заготовленими репліками.

> Ключ у браузері видно будь-кому з доступом до пристрою — не використовуйте
> робочий ключ на чужому компʼютері.

## Стек

Без залежностей. Сцена малюється на `<canvas>` у фіксованих логічних координатах
(364×276) і масштабується під екран, тому композиція однакова на телефоні й десктопі.
Персонажі — піксельні мапи 12×18, меблі — ізометричні паралелепіпеди з сортуванням
за глибиною.

- `index.html` — розмітка та панель керування
- `style.css` — інтерфейс
- `agency.js` — рендерер сцени + рушій симуляції
