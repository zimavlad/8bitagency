# 8bitagency

Гра про маленьку креативну агенцію в піксельному ізометричному офісі. Ти — власник.
Команда: стратегиня (мила, як з аніме), копірайтер (прогресивний хіпстер-технар) і дизайнер
(бородатий, патлатий). Брифи приходять від українського бізнесу — сирі й наївні, як у житті, —
або пишеш свій.

## Як іде бриф

1. **Читання** — кожен сам, наосліп, через свою лінзу 4 правд. Іноді біжить до Джіпітенка.
2. **Суперечка** — кожен цитує найслабше місце колеги (окрема модель ревʼю, Opus).
3. **Основа** — стратегиня: позиціонування з трьох кандидатів, роль і ворог; копірайтер: назва
   й слоган; дизайнер: знак. Обидва — від позиціонування й не бачать одне одного.
4. **Ти** — по одній правці на кожен елемент або «показати клієнту».
5. **Клієнт** — AI-критик, стереотипний бізнес: хоче великий логотип, знижки й гроші.
   Одна хвиля правок, потім «так» або «ні».
6. **Контент** — tone of voice для Threads, креатив для Instagram, ідеї Reels, іміджевий ролик
   для YouTube. Знову твоя правка на кожен і клієнт.
7. **Оплата** — гроші від клієнта, репутація від якості роботи (рахує код, не модель),
   вигорання команди. Щодня −6 000 ₴ на зарплати й оренду.

Конфлікт гри: клієнт платить за перфоманс-штампи, а репутація від них падає.
За вікном — справжня година й погода в Києві.

## Джіпітенко і база знань

Стратегиня й копірайтер іноді радяться з Джіпітенком (дизайнер — майже ніколи). Він відповідає
з бази знань ролі: файли PDF, MD або TXT у

    <DATA_DIR>/knowledge/strategist/
    <DATA_DIR>/knowledge/copywriter/
    <DATA_DIR>/knowledge/designer/

На сервері `DATA_DIR=/data`, локально — `./data`. База перечитується сама, коли зʼявляються нові файли.

## Запуск

    npm install
    npm run dev       # http://localhost:5173
    npm test
    npm run check
    npm run build && npm start

Без `ANTHROPIC_API_KEY` відповідає підставна модель (позначка «демо»). Змінні — `.env.example`.
`?h=23&w=rain` в адресі підміняє годину й погоду для перевірки.

## Стек

SvelteKit (adapter-node) + Svelte 5 + Sass + TypeScript + vitest, `@anthropic-ai/sdk`.
Ключ Claude лише на сервері. Стан гри — `save.json` на томі `/data`; база — наступним етапом.

- `src/lib/server/game/` — рушій брифу, персонажі, брифи, перевірки, база знань
- `src/lib/server/model/` — Claude і підставна модель
- `src/lib/scene/` — ізометричний офіс і спрайти
- `src/lib/components/` — інтерфейс
